# 知识库删除功能使用说明

## 启动

在项目根目录执行：

```powershell
streamlit run app.py
```

## 界面新增功能

左侧栏新增“知识库管理”：

1. 显示当前文档数和文本块数。
2. 多选知识库中的旧文档并删除。
3. 输入“清空知识库”后，彻底删除整个 Chroma collection。
4. 删除向量数据时同步删除 `data/uploads/` 中的原文件。
5. 默认开启“同名文档自动覆盖”，避免重复上传产生重复文本块。

## 推荐的污染库重建流程

1. 在左侧“知识库管理”中输入 `清空知识库`。
2. 点击“彻底清空全部知识库”。
3. 重新上传干净文档。
4. 保持“同名文档自动覆盖”开启。
5. 点击“构建 / 更新知识库”。
